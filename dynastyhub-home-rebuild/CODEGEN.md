# Build Instructions for Codegen

Codegen/LLM tools: create a NEW folder at the repo root called `/code` and put the app files there:
- `/code/index.html`
- `/code/app.js`
- `/code/styles.css`

**Do not** modify `/src`. Treat `/src` as a working example only.
Use runtime data from `/data` and design tokens from `/design`.
