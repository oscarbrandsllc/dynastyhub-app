# Interactions & State

## AppState (initial)
- Selected player: **Jeanty** (expand later with more players).

## Interactions
- Clicking a chip switches the bound dataset (when more players are added).
- Prev/Next cycles through the same list (wrap-around).
- Radar and sparkline update with the selected player.
- Stat cards read from precomputed values (e.g., 95.1%, 94.3%, 98.1%, 89.3% for Jeanty).

## Acceptance Checks
- Initial render matches the screenshots.
- All iframes load and are responsive.
- Radar & sparkline draw without errors.
